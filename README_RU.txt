RPG LIFE LEVELING — Android-проект

ВАЖНО: этот архив — исходный проект, а не уже собранный APK.

Сборка APK в облаке (можно начать с телефона):
1. Создай репозиторий на GitHub.
2. Загрузи СОДЕРЖИМОЕ этой папки в корень репозитория (не сам ZIP-файл).
3. Открой вкладку Actions и запусти workflow "Build RPG LIFE LEVELING APK".
   Если workflow не виден, сначала сделай commit в ветку main.
4. После завершения сборки открой запуск workflow и скачай artifact
   "RPG-LIFE-LEVELING-APK". Внутри будет app-debug.apk.
5. Скачай APK на Android и открой его для установки. Возможно, Android попросит
   разрешить установку из используемого браузера/файлового менеджера.

Для локальной сборки: Android Studio, JDK 17, Android SDK Platform 35.
В приложении содержится локальный HTML-проект в app/src/main/assets/index.html.
Кнопка ChatGPT открывает внешний ChatGPT; сама модель не встроена в APK.
