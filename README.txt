RPG LIFE LEVELING — PWA-пакет

Что внутри:
- index.html — сама игра
- manifest.webmanifest — настройки установки как приложения
- sw.js — кеширование для работы офлайн после первого открытия
- icon.svg — иконка приложения

Как установить на Android:
1. Размести все файлы из этой папки на HTTPS-хостинге (например, GitHub Pages или Netlify).
2. Открой адрес сайта в Chrome на Android.
3. Открой меню ⋮ и выбери «Установить приложение» или «Добавить на главный экран».
4. После установки игра будет запускаться отдельным окном, как приложение.

Важно:
- Для установки PWA нужен HTTPS-адрес или localhost; открытие index.html как локального файла не даст полноценную установку.
- Прогресс сохраняется в локальном хранилище браузера на этом устройстве.
- Этот пакет не является APK и пока не синхронизирует данные с ChatGPT.

Квесты: 600 содержательных миссий — по 6 на каждый из 100 бустов; у каждой миссии четыре уровня нагрузки.
